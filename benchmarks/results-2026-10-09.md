# Installed compiler benchmark observations — 2026-10-09

These are historical results from the outdated installed binary. The compiler
has since been built in release and installed; see the
[release rerun and bottleneck analysis](results-release-2026-10-09.md).

Compiler: `/home/cesar/.local/bin/tarn`, version 0.0.1.
SHA-256: `a5555e89196da696718a8bc61d10a357d4eae7e423f2986f4abd9d6957c885ff`.
Go: go1.26.0 linux/amd64. The installed compiler differs from target/release/tarn.
No compiler rebuild or installation was performed.

These are observations on a desktop with other applications active, without CPU
isolation. Some HTTP/native validation overlapped the comparison run. Timing
precision in the shell runner is 0.01 seconds; short-case ratios are noisy.
All nine comparison cases produced matching outputs. The runner was edited while
the first run was active, causing an EOF error after its final result; shell syntax
was verified and tasks was rerun successfully with the final script.

## Tarn versus Go

Command: `./benchmarks/vs-go/run.sh arith fib vec strings strings-ranges enums jsoncodec parallel tasks`.
Median of five executions, seconds; ratio is Tarn time divided by Go time.

| Case | Tarn | Go | Ratio |
|---|---:|---:|---:|
| arith | 2.85 | 0.65 | 4.4x |
| fib | 0.09 | 0.07 | 1.3x |
| vec | 0.41 | 1.16 | 0.4x |
| strings | 3.04 | 0.23 | 13.2x |
| strings-ranges | 2.24 | 0.23 | 9.7x |
| enums | 0.29 | 0.58 | 0.5x |
| jsoncodec | 1.10 | 0.27 | 4.1x |
| parallel | 2.21 | 0.49 | 4.5x |
| tasks (final-script rerun) | 0.68 | 0.03 | 22.7x |

Both vector cases now grow from empty; older capacity-reserving results are not
directly comparable. The ranges case uses a benchmark-local ASCII delimiter
helper, not the newer embedded string.split_ranges API. Native Tarn tasks and Go
goroutines have different execution models. These measurements do not establish
an improvement over the compiler used in the Phase 28 report.
